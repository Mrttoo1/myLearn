# 教学页面：先看流程，再看代码

首页是交互课程；右上角“学习记录”通往真实的增删改查练习。

## 建议的学习顺序

1. 打开“一条记录的旅程”，手动点击“下一步”。每步先读一句话解释，再看右侧代码和输入输出。
2. 停在 `session.add` 和 `session.commit`，比较对象状态与数据库写入的区别。
3. 切换“项目文件”，对照 `routers`、`schemas`、`services`、`models` 和 `database.py` 的职责。
4. 打开“真实请求”，先尝试空标题的 422，再发送一条正常记录，观察 201。
5. 去 `/notes` 查看保存结果，再刷新页面，确认数据来自数据库。
6. 回到错误排查课程，比较 422、404 和 503 发生的位置。

正常保存实验会真正写入数据库；分步演示中的数据与 SQL 是讲解用的示例，不会产生数据库操作。

## 服务启动与请求处理是两条流程

启动时先运行 PostgreSQL，再执行 Alembic 迁移，之后启动 Uvicorn/FastAPI，最后启动 Vite。迁移是后端目录中的独立命令，不是某个 HTTP 接口。

运行期间，一次请求经开发代理到达后端，完成校验与业务处理，再通过数据库会话执行 SQL。SQLAlchemy 是 Python 库；PostgreSQL 是独立服务。

启动时数据库连接超时会使迁移失败，此时后端尚未开始监听。运行中的后端遇到数据库异常，则会由异常处理器返回 503。两种情况要分开排查。

## 消息如何播放、暂停和查看

看 `frontend/src/composables/useLessonPlayer.ts`：

- `index` 表示当前步骤，`progress` 表示本条消息从发出到到达的进度。
- 点击“下一步”，GSAP 用约 0.95 秒播放完整的一次发送，到达后停住。自动播放时，再留约 1.65 秒阅读，然后发送下一条；倍速同时影响这两段时间。
- 暂停保留消息位置，继续后从原处完成。切换步骤、课程或离开页面时取消旧动画，避免多个动画互相影响。
- 查看已经发生的消息，只改变右侧讲解与源码，不回退演示。点击尚未发生的消息则跳到那一步并演示。

`FlowDiagram.vue` 始终显示 Vue、Vite、FastAPI 和 PostgreSQL，启动课额外显示终端。点击“下一步”只改变消息位置、连线和当前处理状态；本地处理也保留其他模块。尚未启动的服务会明确标注，不会从图中消失。

图示按运行环境分组：浏览器与 Vite 共用本机前端区域，数据库、后端和终端使用各自的小区域。设备是紧凑插图，位置在整节课中保持固定。消息在实际连接上移动，调用名始终显示在图下方；简写的浏览器与后端请求也会经过 Vite。

切换到“时序图”可以查看完整消息列表和参与角色。过去、当前、未来的消息使用不同状态；点击消息可以查看对应代码。下方过程记录也支持相同操作。

`frontend/src/lessons/flow.ts` 存放角色、固定坐标与连线。消息从设备侧面发出；经过代理时，入站与出站分别播放，不会画一条穿过 Vite 的直线。未来连接显示为虚线，经过的连接显示为实线，当前连接高亮。减少动态效果偏好开启时，消息和轨迹固定在到达位置，保留方法名与讲解。

动画不是 Python 调试器，也不会暂停真实服务器的事务。“真实请求”面板独立展示实际的 HTTP 结果和耗时。

## 这次参考了哪些交互

本轮核对了 [MCP Explained 的公开实现](https://github.com/runlayer/mcp-explained)：带名称的消息、单步完整发送、历史消息检查和完整时序列表。课程、步骤与源码映射仍围绕本项目编写。

运行 `cd frontend`、`pnpm test` 可以验证模块与坐标在整节课中保持不变、连接状态、消息方向、完整行程、暂停恢复，以及切换课程时取消旧队列。它们是逻辑测试，不能代替浏览器中的视觉检查。本轮浏览器连接不可用，尚未完成当前版本的桌面和手机实测。

## 代码区如何对应真实文件

`frontend/lessonSourcesPlugin.ts` 使用固定白名单，在开发或构建时读取源码，提供给前端虚拟模块。课程数据通过文件路径和代码锚点选出相关片段及行号。

开发时修改白名单中的源码会触发页面刷新。正式构建后展示构建时的版本，更新源码后需要重新构建。

白名单不包含 `.env`、工具目录和数据库文件，也没有为浏览器开放任意文件读取接口。

## 如何增加课程

先阅读 `frontend/src/lessons/content.ts`。每个步骤包含标题、解释、文件路径、代码锚点、数据流方向、输入和输出。

增加步骤时，先确认它对应项目中的真实行为；涉及新文件时，更新源码白名单。优先复用现有图示和播放器，保持讲解内容与显示逻辑分离。
